# AWS

## Overview

This repository demonstrates fundamental cloud computing concepts using Amazon Web Services (AWS). The project focuses on two core AWS services:

- Amazon EC2 (Elastic Compute Cloud)
- Amazon S3 (Simple Storage Service)

The objective of this project was to gain hands-on experience with launching cloud resources, connecting to virtual machines, creating storage buckets, and managing bucket permissions.

---

## Services Used

### Amazon EC2
Amazon EC2 provides scalable virtual servers in the cloud.

### Amazon S3
Amazon S3 is an object storage service used to store and retrieve data securely.
